Family Book Build 3.1 — Memories breakthrough

NEW
- Real Memories page replacing the placeholder.
- Upload a photo from Gallery or take a photo with the phone camera.
- Photos are resized/optimized in the browser before storage.
- Memories use IndexedDB rather than localStorage so photo data is not squeezed into the small localStorage limit.
- JPEG EXIF DateTimeOriginal / DateTimeDigitized / DateTime metadata is checked automatically.
- If original photo date/time is found, Date and Time fields are pre-filled.
- Date and time remain fully editable before save and later through Edit Memory.
- If a photo is taken directly and no EXIF time is available, current date/time is suggested and remains editable.
- Caption/story field.
- Tag any Family Book member in the photo.
- Memories gallery, full memory view, edit and delete.
- Member tags in a memory link to that member's profile.
- Fake notification count "3" removed until real notifications exist.

- Clearing browser site data can remove locally stored memories.
- A future cloud-storage build should sync the photo library across family accounts/devices and preserve originals.
