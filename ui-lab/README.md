# FamilyBook UI Lab

This folder belongs to the `ui-redesign-lab` branch and is intentionally isolated from the live FamilyBook interface.

## Rules for this branch

- Do not merge UI experiments into `main` without explicit approval.
- Do not connect production family data while the visual direction is still being explored.
- Build new screens here first, compare them with the live product, then move only approved components into production.
- The goal is a recognisably original FamilyBook interface: private family journal / archive first, social network second.

## Starting point

`ui-lab/index.html` is the first neutral redesign canvas. It is deliberately not a copy of the current Home page.
